Manim Tech Visuals

Visual explanations of algorithms, ML concepts, and research ideas, created using the Manim Python library.
This repository showcases animations I made to better understand (and explain) concepts I analyzed or implemented—such as diffusion models, flow matching, robotics pipelines, and more.

🚀 Overview

This project is a collection of Manim animations that transform complex technical ideas into clear visual explanations.
It is intended as a portfolio for job applications, demonstrating:

Ability to communicate technical ideas visually

Understanding of ML, robotics, and algorithmic concepts

Proficiency in Python and Manim

Experience converting formulas & research concepts into code

🧠 Motivation

I often analyze research papers or implement frameworks for robotics and machine learning.
To deepen my understanding, I build animations that explain:

    - How models work internally
    - How algorithms transform data
    - The meaning behind key mathematical steps
    - The relationship between encoders, policies, and decoders

This repository is both a study tool and a portfolio.

🔒 Why Animations Instead of Code?

Due to code security and confidentiality restrictions in the hospital environment where part of my research is conducted, I am not allowed to upload project source code or certain implementation details publicly.

To still communicate my understanding and demonstrate my work, I use Manim animations to visually explain:
 
    - Models I analyzed
    - Pipelines I implemented
    - Frameworks I worked with
    - Concepts from restricted codebases

These animations serve as a safe and effective way to showcase my technical reasoning, understanding of algorithms, and ability to translate research into working systems—without exposing sensitive code.
